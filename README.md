# UAD Mods — конструктор модів

Сайт для створення модів до гри [Ukraine Air Defense](https://github.com/MikeLiashenko/UAD):
блоки (легко) і Python (для складного), графіка поверх картинки гри, файл `.uadmod` для гри.
Відкривається на <https://mikeliashenko.github.io/UAD-Mods/>.

- **Блоки** (Blockly, стиль zelos): нові системи ППО й загрози — **тип** (ствольна, ПЗРК, ракети
  ближнього / середнього / дальнього рубежу, ПРО, дрони; розвідник, ударний / реактивний дрон, хибна
  ціль, крилата ракета, КАБ, балістика, аеробалістика) і **модель** (наша або своя), зміна полів,
  нальоти, події гри (ціль збито, прорив, ніч, ранок, покупка, кожні N секунд), дії (повідомлення,
  гроші, запуск загроз, системи й ракети, ремонт міста), пам'ять світу (`uad.data`), логіка, цикли,
  змінні. Блоки пишуть Python для модуля `uad` гри (`scripts/mods/mod_api.gd` у репозиторії гри).
- **Код**: той самий Python у редакторі (CodeMirror). Правка вручну відв'язує код від блоків.
- **3D-моделі** (three.js, `js/editor3d.js`, `js/models_tab.js`): деталі — коробка, циліндр, конус,
  куля, призма; стрілки рухають, повертають і змінюють розмір; колір, матеріал, частина (корпус,
  башта, ствол, гвинт), осі башти, ствола, дула й гвинта; копія, дзеркальна копія, відміна. Будь-яку
  модель гри можна взяти за основу (`js/models.js`, вивантажено грою: `-- --exportmodels=models.json`).
  Формат — `«ім'я.uadmodel»`, той самий, що в грі (`scripts/mods/model3d.gd`); моделі їдуть у `.uadmod`.
- **Графіка**: ефекти з повзунками → шейдер Godot `canvas_item` (`.uadshader`); ті самі рядки в
  GLSL ES 3.00 показують попередній перегляд на скриншоті гри. Може їхати всередині мода.
- **Файл**: `.uadmod` — zip із `mod.json`, `main.py`, `blocks.json` (щоб сайт міг відкрити мод знову;
  гра читає лише перші два) і, за бажанням, `picture.uadshader`.
- Мови: українська, російська, англійська (вибір спільний із сайтом гри). Проєкт зберігається в браузері.

Без збирання: статичні файли, бібліотеки з CDN (Blockly 11.2.1, CodeMirror 5.65.16, JSZip 3.10.1).
Локально: `py -m http.server 8765` у цій теці і <http://localhost:8765>.

`js/data.js` — системи й загрози гри з назвами (з `scripts/autoload/gs.gd` гри); при нових системах у
грі його треба оновити.
